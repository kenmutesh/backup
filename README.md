# Laravel Backup Package

A comprehensive backup solution for Laravel applications, similar to Spatie's backup package.

## Features

- Database backup (MySQL, PostgreSQL, SQLite)
- Files backup with include/exclude patterns
- Compression support
- Automatic cleanup of old backups
- REST API endpoints
- Web interface for managing backups
- Artisan commands
- Queue support
- Event notifications

## Installation

```bash
composer require yourname/laravel-backup
